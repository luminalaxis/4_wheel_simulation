# 모델 수식과 가정

`aerolap`은 **준정적(quasi-steady-state, QSS)** 랩 시뮬레이터입니다. 매 순간 차량이 주어진
`(v, ax, ay)`에서 정적 평형에 있다고 보고, 그 평형을 OptimumLap의 점질량 대신 **4륜 하중 +
서스펜션 변위 + 자세 의존 공력**으로 풉니다. 기호: 질량 `m`, 휠베이스 `L`, CG에서 앞축까지 `a`,
뒷축까지 `b`, CG 높이 `h`, 트레드 `t_f, t_r`, `q = ½ρv²`.

모든 함수는 numpy 배열을 받아 GGV 격자 전체를 한 번에 계산합니다 (`src/aerolap/vehicle.py`).

## 1. 공기 밀도 (`environment.py`)

습공기: `ρ = p_d/(R_d T) + p_v/(R_v T)`, `p_v = RH · p_sat(T)` (Buck 식). 기압을 주지 않으면 고도에서
ISA 기압을 계산합니다. ISA 해면 15 °C → 1.225 kg/m³.

## 2. 공력 (`aero/maps.py`)

```
DF_f = q · ClA_f(rh_f, rh_r, |φ|, |β|, mode)
DF_r = q · ClA_r(rh_f, rh_r, |φ|, |β|, mode)
D    = q · CdA (rh_f, rh_r, |φ|, |β|, mode)
```

- `rh_f, rh_r`: 앞/뒤 축 위치의 차고, `φ`: 차체 롤, `β`: 차체 슬립각(공력 yaw), `mode`: 공력 모드(예: `high_df`, `drs`)
- 맵 종류: `constant`(OptimumLap과 같은 상수), `table`(전 격자 다선형 보간), `response_surface`(CFD 산발점에 2차 응답면 최소제곱 피팅)
- 맵 범위를 벗어나면 경계값으로 클램프하고 `aero_out_of_range` 플래그를 남깁니다
- 셋업 노브: `ClA_total ×= cla_scale`, `CoP_front += cop_shift`, `CdA ×= cda_scale`
- 다운포스의 좌우 작용점은 롤에 따라 `y_cp = k_lat·|φ|`만큼 바깥쪽으로 이동할 수 있습니다(`cop_lateral_shift_mm_per_deg`). 이것은 현가 질량에 롤 모멘트를 더합니다.

## 3. 타이어 하중 (`VehicleModel.suspension_response`)

정적 축하중: `W_f = m g b/L`, `W_r = m g a/L`.

**종방향** (뒤로 이동하는 하중):

```
ΔF_long = (m·ax·h + D·h_drag) / L
```

항력이 지면 위 `h_drag`에서 작용하므로 등속 주행에서도 뒤로 하중이 이동합니다(OptimumLap에는 없음).

**횡방향** (축별, 바깥 바퀴에 +, 안쪽 바퀴에 −):

```
φ        = [m_s·ay·d + (DF_f+DF_r)·y_cp] / (K_f + K_r − m_s·g·d)        (롤각)
ΔFz_f    = [K_f·φ + m_s·ay·(b_s/L)·h_rcf + m_uf·ay·r] / t_f
ΔFz_r    = [K_r·φ + m_s·ay·(a_s/L)·h_rcr + m_ur·ay·r] / t_r
```

- `m_s`: 현가 질량, `d`: 현가 질량 CG의 롤축 위 높이, `h_rc`: 롤센터 높이, `r`: 타이어 반경
- 첫 항이 **탄성 성분**(스프링·ARB가 받음, 롤강성 배분 `K_f/(K_f+K_r)`으로 나뉨), 둘째 항이 **기하학적 성분**(링크가 받음), 셋째 항이 비현가 질량 성분
- 축 롤강성 `K = (k_w t²/2 + K_arb)`과 타이어 롤강성 `k_t t²/2`의 직렬 결합

**바퀴 하중**: `Fz = 축하중/2 ± ΔFz`. 음수가 되면 0으로 자르고 `wheel_lift` 플래그를 남깁니다.

## 4. 서스펜션 변위 → 차고, 롤, 캠버

스프링이 받는 하중(탄성 성분)과 타이어가 받는 하중(전체)을 나눠 계산합니다.

```
ΔF_el,f = DF_f − ΔF_long,sprung·(1 − anti_f) − D·h_drag/L
rh_f    = rh_f,static − ΔF_el,f / (2 k_w,f + k_3,f) − (축하중_f − W_f) / (2 k_t)
```

- `k_w = k_spring · MR²` (휠레이트), `k_3` = 3rd(히브) 스프링, `k_t` = 타이어 수직 강성
- anti-dive(앞, 제동), anti-lift(뒤, 제동), anti-squat(뒤, 구동) 비율만큼은 링크로 전달되어 스프링을 누르지 않습니다
- 피치 = 앞/뒤 차고 변화 차이 / L, 바닥 간극 = `min(rh_f, rh_r) − (floor_width/2)·sin|φ|`
- 코너 범프 = 축 히브 ± (t/2)·φ_susp, 캠버 = 정적 캠버 + 캠버 게인 × 범프 ± φ (바깥 바퀴 +)

## 5. 타이어 그립 (`tire.py`)

```
μ(Fz) = μ0 · max(1 + k·(Fz − Fz0)/Fz0, min_factor)        (하중 민감도, k<0 이면 체감)
F_y,max = μ_y(Fz) · Fz · (1 − c_γ·(ε − ε_opt)²)             (ε: 회전 중심 쪽 기울기)
F_x,max = μ_x(Fz) · Fz · (1 − c_γ·γ²)
```

축별 마찰 타원 `(Fx/Fx_cap)² + (Fy/Fy_cap)² ≤ 1`. 같은 다운포스라도 어느 바퀴에 실리느냐에 따라
(하중 민감도 때문에) 그립 이득이 달라지는 것이 4륜 모델의 핵심입니다.

## 6. 실현 가능성 (`VehicleModel.evaluate`)

- 정상상태 요 모멘트 평형: `Fy_f = m·ay·b/L`, `Fy_r = m·ay·a/L`
- 종력 요구: `Fx = m·ax + D + C_rr·ΣFz` — 양수면 구동축(RWD/AWD, LSD/오픈 디퍼렌셜), 음수면 브레이크(이상적 배분 또는 고정 바이어스, 좌우 같은 압력 → 안쪽 바퀴가 먼저 한계)
- 파워트레인: `F_drive + m_rot·max(a_x, 0) ≤ F_max(v)` (ICE는 기어별 최대, EV는 모터 토크–속도 곡선과 배터리 출력 한계,
  `m_rot`는 로터 관성을 바퀴로 환산한 등가 질량 — 6.1절)
- 이용률 `u = max(u_front, u_rear, u_power) ≤ 1` 이면 실현 가능. 어느 항이 최대인지가 "한계 요인"
- **언더스티어 지수** `u_y,f / u_y,r`: 1보다 크면 앞축이 먼저 포화(언더스티어 한계, 안정), 1보다 작으면 뒷축이 먼저 포화(오버스티어 한계)

### 6.1 전기 모터와 배터리 (`motors.py`, `powertrain.py`)

`motor: emrax_228`이면 데이터시트(EMRAX 228 v1.7) 값으로 모터를 만듭니다.

```
n_base = KV_peak_load · V_dc                           (역기전력이 직류 전압에 도달하는 속도)
T(n)   = min(220 Nm, KT · I_controller)                  n ≤ n_base
       = T(n_base) · n_base / n                          n_base < n ≤ 6500 rpm   (약계자, 정출력)
P      ≤ 124 kW
F_wheel = n_motors · T · G · η_drivetrain / r
P_battery = T ω n_motors / (η_motor(n, T) · η_inverter) ≤ power_limit_kW
η_motor = P / (P + 3 (T/KT)² R_phase + c0 + c1 n + c2 n²)
m_rot   = n_motors · J_rotor · G² / r²
```

| 권선 | KV(최대부하) [rpm/V] | KT [Nm/A] | 최대 전류 [A] | 상저항 [mΩ] | 최대출력 전압 [V] |
|---|---|---|---|---|---|
| HV | 5.65 | 0.98 | 235 | 16.09 | 830 |
| MV | 8.68 | 0.64 | 360 | 6.95 | 630 |
| LV | 21.91 | 0.24 | 920 | 1.36 | 250 |

- 데이터시트 대조: MV 630 V → 기저 5468 rpm, 5500 rpm에서 124 kW(데이터시트 "124 kW at 5500 rpm"); HV 830 V → 4500 rpm에서
  104 kW("104 kW at 4500 rpm")
- 효율: 동손은 데이터시트 상저항·KT로 계산하고, 속도 손실 `c0 = 120 W, c1 = 0.04 W/rpm, c2 = 6·10⁻⁵ W/rpm²`은 효율 맵
  (최대 96 % — 3000 rpm·110 Nm 부근, 1000 rpm·20 Nm에서 86–90 %, 500 rpm 저토크 86 % 미만)에 맞춘 근사입니다. 고속·고토크
  영역(5000 rpm 이상, 150 Nm 이상)은 맵보다 약 2 %p 높게 나옵니다. 측정 맵이 있으면 그것이 정확합니다
- 로터 관성 0.0398 kg·m²(LC), 감속비 3.6, 타이어 반경 0.203 m → 등가 질량 12.5 kg. 출력 한계 구간의 가속에 반영되고
  타이어 그립 계산에는 들어가지 않습니다
- 연속 정격(S1): AC 83 Nm / 48 kW, LC 118 Nm / 68 kW, CC 130 Nm / 75 kW. 내구 종목에서 랩의 RMS 토크와 평균 출력을 이 값과 비교합니다
- 에너지 = 배터리 출력의 시간 적분(회생 시 회수분을 뺌)

### 6.2 배터리 용량과 에너지 한계 내구 (`battery:`, `analysis/energy.py`)

```
P_limit   = min(powertrain.ev.power_limit_kW, battery.max_power_kW)          (배터리 측)
E_usable  = capacity_kWh · usable_fraction
P_regen   = min(regen_power_kW, F_regen v η_drivetrain η_motor η_inverter),  F_regen = min(regen_axle_share · F_brake, T_max G / r)
E_lap     = ∫ (P_battery − P_regen) dt
```

- 랩 에너지 분해: `E_battery = W_wheel + 손실 − E_regen`, `W_wheel = ∫F_drive v dt = 항력 + 구름저항 + 제동 + Δ운동에너지`
  (제동 항 = 브레이크 열 + 회생으로 들어간 몫). 폐회로 flying lap이면 Δ운동에너지 ≈ 0
- 내구: `N = round(거리 / 트랙 길이)` 랩, 한계 주행 에너지 `N · E_lap`이 `E_usable`을 넘으면 출력 캡 `P_cap`을 이분법으로
  낮춰(거친 엔벨로프로 이분법 → 정밀 엔벨로프로 다시 구간을 잡아 0.25 kW까지 이분법) `N · E_lap(P_cap) ≤ E_usable`이 되는
  최대 캡의 랩타임을 씁니다
- **셀 기반 팩 모델**(`battery.cell`, `battery.py`): `V_oc = N_s·OCV(SOC)`, `R = N_s·R_cell/N_p + R_ic`,
  `I_max = min(N_p·I_cell, I_pack, (V_oc − N_s·v_min)/R, V_oc/2R)`, 단자 출력 `P_t = V_oc·I − R·I²`,
  `I(P) = (V_oc − √(V_oc² − 4RP))/2R`, `V_t = V_oc − R·I`. 출력 상한 `min(규정, P_t(I_max))`, 모터 직류 전압 = 그 출력에서의 `V_t`.
  셀 에너지 = `∫(P_t + R·I²)dt`, 사용 가능 = `N_s·N_p·Ah·∫OCV dSOC`(soc→soc_min). 내구는 SOC 단계마다 랩을 다시 풀고
  `ΔSOC = 랩 수·∫I dt / (N_p·Ah·3600)`. 셀 온도·SOC별 저항 변화·과도 전압(RC)은 없음
- 회생은 블렌딩이 이상적이라고 가정해 속도 프로파일은 그대로 두고 에너지만 회수합니다. 리프트 앤 코스트, 랩별 SOC·전압 강하,
  배터리 온도는 모델링하지 않습니다(전압은 `dc_voltage_V` 고정)

## 7. 요(차체 슬립각)

타이어 정규화 횡력 곡선 `Fy/Fy_max = 2x/(1+x²)`, `x = α/α_peak`를 역으로 풀어 축 슬립각을 얻습니다.

```
β = b·κ − α_r,     δ = L·κ + α_f − α_r      (κ = ay/v²)
```

`β`가 공력 맵의 yaw 입력이 됩니다. 저속 급코너에서는 `b·κ`가 커서 큰 양의 yaw, 고속에서는 `−α_r`이 지배합니다.

## 8. 연성 평형 (`VehicleModel.solve_state`)

공력 → 하중 → 차고·롤 → 슬립각 → 공력 … 을 **고정점 반복**으로 풉니다(허용오차 1e-5 m / rad,
최대 40회, 미수렴 시 `not_converged` 플래그). 예제 차량의 GGV 전 격자에서 수렴합니다
(`tests/test_vehicle.py::test_fixed_point_converges_on_whole_envelope`).

## 9. QSS 솔버 (`solvers/ggv.py`, `solvers/qss.py`)

1. **GGV**: 속도 격자마다 `ay_max(v)`(ax=0, 항력 극복 포함), 그리고 `ay = f·ay_max(v)` (`f = sin θ`, θ 균등)
   격자에서 최대 가속 `ax_acc`, 최대 감속 `ax_brk`, 타력 감속 `ax_coast`를 벡터화 이분법으로 계산합니다.
   격자의 모든 점이 연성 평형이므로 제동 피치, 코너 롤·요에 의한 공력 변화가 이미 포함됩니다.
2. **정점 속도**: `v²|κ| ≤ ay_max(v)`를 아래에서부터 만족하는 최대 속도
3. **전진 적분**(Heun, v² 공간): `v_{i+1}² = v_i² + (a₁ + a₂)·Δs_i`, 정점 속도로 캡. ICE는 업시프트 동안 `shift_time_s` 만큼 구동력 0
4. **후진 적분**: 같은 방식으로 제동 엔벨로프, 최종 속도 = 두 결과의 최솟값
5. **트랙 이산화**: 좌표 트랙(`x_m,y_m`, Assetto Corsa `fast_lane.ai`)은 호 길이 재샘플링 후 Whittaker 평활화
   `(I + λ D₃ᵀD₃) x̂ = x`, `λ = (L_c / 2π h)⁶`(차단 파장 `L_c`, 기본 8 m, AC 10 m)로 점 잡음을 지우고 중앙차분으로 곡률을 구합니다.
   세그먼트 트랙은 세그먼트 경계에 노드를 두고 각 구간이 고유 곡률을 갖습니다(코너 출입구가 정확히 해석됨, ds 1 m → 0.125 m 랩타임 변화 < 0.01 %)
6. **폐회로**: 3바퀴를 이어 풀고 가운데 바퀴를 사용(시작 속도 주기성)
7. **후처리**: 최종 속도 프로파일의 ax, ay로 평형을 다시 풀어 거리별 차고, 롤, 요, ClA, CoP, 바퀴 하중, 캠버, 한계 요인, 구동 에너지를 기록

## 10. 액티브 에어로 / DRS (`aero/strategy.py`)

- `fixed`: 한 모드
- `rule`: 반경 > `open_radius_m`, 길이 ≥ `min_length_m`, 속도 ≥ `min_speed_kmh`, 제동·코너 한계가 아닌 곳에서 개방.
  개방에 `open_delay_s`, 폐쇄에 `close_delay_s`가 걸리고 그동안은 저다운포스 상태로 간주합니다.
  `close_anticipation: false`이면 제동을 시작해야 닫히기 시작합니다. 제동점이 모드에 의존하므로 모드 배열이 수렴할 때까지 반복합니다.
- `ideal`: 매 지점 가속·제동·정점 한계가 더 좋은 모드 → 액티브 에어로가 줄 수 있는 이득의 상한

## 11. 효과 단계 (effect ladder, `features.py`)

| 레벨 | 추가되는 효과 |
|---|---|
| L0 | OptimumLap 동등: 점질량(하중이동 없음), 다운포스는 정적 하중비로 배분, 공력 계수는 정적 차고에서 고정 |
| L1 | 4륜 종·횡 하중이동 (하중 민감도가 실제로 작동) |
| L2 | 공력 밸런스(맵의 CoP) + 항력 작용 높이 |
| L3 | 히브·피치에 의한 차고 변화가 공력 맵에 반영 |
| L4 | 롤·요가 공력 맵에 반영, 캠버 변화가 그립에 반영 |
| L5 | 액티브 에어로 / DRS 전략 |

## 12. 과도(transient) 솔버 (`solvers/transient.py`)

상태: 경로 위치 `s`, 속도 `v`, 현가 질량 히브 `h`·피치 `θ`·롤 `φ`, 바퀴 4개의 수직 변위 `w_i`(모두 속도 포함),
차체 슬립각 `β`, 플랩 개도 `λ ∈ [0, 1]`, 타이어 유효 하중. 주 시간 간격 `dt`(기본 5 ms), 라이드(차체+바퀴) 동역학은
`ride_dt`(기본 0.5 ms)로 나눠 반암시적 오일러 적분합니다. 라이드 상태는 **차량 좌표(좌/우)** 로 두어, 방향 전환 순간에
남아 있는 롤이 그대로 이어집니다.

### 12.1 7자유도 라이드 모델 (`RideModel`)

코너 i의 차체 변위(아래 +) `d_i = h + x_i θ + y_i φ` (`x`: 앞 +a_s / 뒤 −b_s, `y`: 좌 −t/2 / 우 +t/2),
서스펜션 압축 `δ_i = d_i − w_i`, 타이어 압축 `w_i + r_i` (`r`: 노면 높이, 위 +).

```
F_i = k_w δ_i + c_w δ̇_i + (k_3/4)(δ_L + δ_R) ± (K_arb/t²)(δ_R − δ_L)          (코너 스프링·댐퍼·3rd 스프링·ARB)
T_i = max(k_t (w_i + r_i) + c_t (ẇ_i + ṙ_i), −Fz_static,i)                       (타이어, 떨어지면 0 하중)

m_s ḧ   = (E_f + E_r) − Σ F_i
I_θ θ̈   = a_s E_f − b_s E_r − Σ F_i x_i
I_φ φ̈   = M_roll + m_s g d φ − Σ F_i y_i
m_u,i ẅ_i = F_i + G_i − T_i
Fz_i    = Fz_static,i + T_i
```

- `E_f, E_r, M_roll`: QSS에서 스프링이 받을 축하중·롤 모멘트(`VehicleModel.load_components`, 다운포스 포함)
- `G_i`: 링크로 바로 바퀴에 들어가는 몫(anti 지오메트리, 롤센터, 비현가 질량 관성)
- 비현가 질량이 없거나 작으면 코너당 `min_unsprung_kg`(3 kg)를 씁니다. 타이어 감쇠는 `tyre_damping_ratio`(5 %)
- 댐핑은 `damper_rate_Ns_per_mm × MR²`, 없으면 `damping_ratio`로 코너 스프링 기준 임계 감쇠에서 계산합니다(타이어 스프링은
  직렬로 감쇠되지 않으므로 ζ = 1이어도 차체는 약간 오버슈트합니다). 관성 모멘트를 주지 않으면 `I_θ ≈ m_s (0.32 L)²`,
  `I_φ ≈ m_s (0.28 t)²`
- 차고(바닥 높이) = 정적 차고 − (축 좌우 평균의 `d + r`), 즉 노면 위 바닥 높이. aero map은 이 **동적 차고·롤**로 읽힙니다
- 매끈한 노면 정상상태에서는 QSS와 같은 하중이 나옵니다. 롤은 기하학적 하중이동에 의한 타이어 변형까지 포함해 QSS보다 약 10 % 큽니다

### 12.2 노면 (`road.py`)

- ISO 8608: `Gd(n) = Gd(n0)·(n/n0)⁻²`, `n0` = 0.1 cycles/m, 등급 A(16e-6 m³) / B(64e-6) / C / D / E.
  파장 0.33–50 m(타이어 접지면보다 짧은 요철은 감싸서 걸러짐), 좌우 상관은 장파장일수록 큼(`exp(−n/0.3)`). 폐회로 트랙은 주기적
- 측정 프로파일 CSV: `s_m,z_left_mm,z_right_mm` (또는 `z_mm` 한 열)
- 앞바퀴는 `s + a`, 뒷바퀴는 `s − b` 위치의 노면을 밟습니다

### 12.3 타이어 완화와 그립

그립 계산에 쓰는 하중은 실제 타이어 하중을 완화 길이 `relaxation_length`(0.25 m)만큼 거리 지연한 값입니다:
`Fz_eff += (Fz − Fz_eff)·v·dt/σ`. 고주파 하중 변동이 그대로 그립에 반영되지 않게 하는 효과이며, 남는 손실은 하중 민감도
(`μ(Fz)`가 아래로 볼록)와 바퀴 들림에서 옵니다.

### 12.4 요, 플랩, 드라이버

- (`lateral_dof: false`일 때) `β̇ = (β_ss − β)/τ_β`. `λ`는 `1/open_delay`, `1/close_delay` 속도로 움직이며 두 모드의 공력 계수를 보간합니다.
  QSS 모드 배열에 들어 있는 작동 지연은 빼고 "명령"으로 바꿔 씁니다(지연을 두 번 넣지 않도록)
- 목표 = QSS 속도 프로파일(같은 3 m 진입 라인, 매끈한 노면). `ax_cmd = a_ref + k_p (v_ref − v)`
- 저크 한계: 제동·가속을 거는 쪽 `max_jerk`(150 m/s³), 푸는 쪽 `max_jerk_release`(400 m/s³). 가감속 전환은 전환 시간의
  절반만큼 미리 시작해 전환점을 중심으로 램프를 만듭니다
- 매 스텝 현재(유효) 타이어 하중에서 타이어·파워트레인이 허용하는 범위로 `ax`를 제한하고, 횡 그립을 넘으면 그만큼 속도를
  잃습니다(미끄러짐)
- 타이어 과사용을 0.1 s 저역통과한 값(지속적인 과사용)이 남은 곳은 목표 속도를 `learn_gain × 과사용`만큼 낮추고 QSS로 다시
  계획해 다음 랩을 달립니다(`iterations`회). 노면 때문에 생기는 순간 스파이크는 학습 대상이 아니라 랩 안의 속도 손실로만 반영됩니다

### 12.5 횡·요 동역학 (`lateral_dof: true`, 기본)

상태(차량 좌표, 왼쪽 +): 횡속도 `v_y`, 요레이트 `r`, 경로 횡오차 `e_y`, 헤딩 오차 `e_ψ`, 앞바퀴 조향각 `δ`.

```
α_f = δ − (v_y + a r)/v_x          α_r = −(v_y − b r)/v_x
F_y,axle = F_y,cap · g(α/α_peak)    g(x) = 2x/(1+x²) (|x| ≤ 1), 이후 sliding으로 0.85까지 완만히 감소
m (v̇_y + v_x r) = F_yf + F_yr       I_z ṙ = a F_yf − b F_yr       v̇_x = a_x + v_y r      (소각도)
ṡ = (v_x cos e_ψ − v_y sin e_ψ)/(1 − κ e_y)    ė_y = v_x sin e_ψ + v_y cos e_ψ    ė_ψ = r − κ ṡ
```

- `F_y,cap`: 그 순간의 유효 타이어 하중·캠버에서 축 횡력 용량. 실제 횡가속도 `(F_yf + F_yr)/m`가 하중이동과 공력 yaw
  (`β = atan(v_y/v_x)`)의 입력이 됩니다
- **횡력 우선 마찰원**: 횡력은 슬립 곡선이 전체 용량으로 만들고, 종방향 한계 계산(`grip_usage`에 축 횡력을 요구값으로 넘김)이
  남은 마찰원 안으로 제동·구동을 제한합니다. 드라이버가 방향을 우선하는 한계 주행에 해당합니다
- **조향 드라이버**: `δ = L κ_ff + (α_f − α_r)_ss − 2L·e_p/L_p² − k_r (r − v κ_ff)`, `e_p = e_y + L_p sin(e_ψ + β)`,
  `L_p = clip(0.25 v + 2, 2.5, 8) m`, `κ_ff`는 0.05 s 앞의 곡률, 정상상태 슬립각은 현재 용량에서 계산, `k_r = 0.08 s`.
  앞 슬립각은 피크의 1.05배까지만 쓰고(그 이상 감아도 횡력이 늘지 않으므로), 조향은 0.03 s 1차 지연
- 라인 바깥으로 밀리면 목표 속도를 `3 (m/s)/m × 바깥 오차`만큼 낮추고(리프트), 뒷바퀴가 피크를 넘으면 가속하지 않습니다
- 차체 슬립각 15° 이상은 스핀: 속도 10 % 손실, 횡 상태를 라인에 맞춰 다시 정렬하고 랩을 계속합니다
- 학습 신호 = max(지속 타이어 과사용, 0.5 × 경로 이탈(`max_path_error` 0.75 m 초과분 비율), 0.5 × 슬라이드(β 8°→15°), 0.5 × 스핀).
  신호가 난 코너(직선이면 30 m 이내 직전 코너)의 **진입 3 m 전부터** 문제 지점까지 기준 속도를 낮춥니다. 코너 안에서는 이미 횡 한계라
  더 감속할 수 없으므로 속도는 진입 전에 줄여야 하기 때문입니다
- 3 m/s 이하는 기구학 모드(`v_y = 0`, `r = v κ`)

## 13. 가정과 한계

- **QSS**: 댐퍼, 서스펜션 고유진동, 피치·롤 과도 응답, 노면은 없습니다. 과도 솔버에도 타이어 온도, 비선형 댐퍼(속도별 감쇠),
  범프 스톱, 바닥(플랭크) 접촉력은 없습니다(바닥 간극은 계산·제약만 함)
- 과도 랩타임에는 단순한 드라이버 모델의 영향(jerk 제한, 최적 트레일 브레이킹·라인 최적화 없음, 횡력 우선)이 섞여 있습니다.
  횡 동역학은 소각도 이륜(bicycle) 근사이며 좌우 바퀴 간 종방향 힘 차이에 의한 요 모멘트(LSD 잠김 등), 공력 요 모멘트·횡력은 없습니다
- 선형 스프링·선형 기하(롤센터 이동, 범프 스티어, 비선형 캠버 커브 없음), 롤과 히브는 독립
- 정상상태 요 모멘트 평형(공력 요 모멘트, 토크 벡터링 없음), 마찰 타원은 축 단위로 같은 이용률을 가정
- 공력 맵은 `|roll|`, `|yaw|`에 대해 대칭이라고 가정, 지면 효과의 히스테리시스 없음
- 트랙은 평면(고저차·뱅크 없음; AC·OptimumLap 트랙의 고도는 읽기만 함), 주행 라인 = 입력한 선(세그먼트·중심선, 또는 AC AI 라인)
- 예제 차량과 aero map(`data/`)은 경향만 그럴듯하게 만든 **가상 데이터**입니다. 실제 판단에는 팀의 CFD/풍동/타이어 데이터를 넣으세요.
